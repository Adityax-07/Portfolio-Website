# Demo-Portfolio reference review

The public `Adityax-07/Demo-Portfolio` repository is cloned into `reference-demo-portfolio/` as an independent reference checkout. Its README describes a GTA VI landing-page recreation, while its React sections contain Aditya's portfolio content.

## Patterns reviewed

- GSAP ScrollTrigger: pinned sections, a mask reveal, scroll-synced video, and staggered entrances.
- Strong project visuals with short metric highlights and direct source/demo links.
- Skill-domain cards with colored glows and certifications.
- A clear contact finish with direct email, phone, and social links.

## Adapted into this site

- Project panels with labeled concept visuals, restrained scroll reveals, and gentle image parallax.
- A concise metric strip and a four-project jump index.
- Three domain cards above the existing full stack list.
- More tactile contact links while retaining the current form and overall page structure.

The GTA images and long pinned video transitions stay in the reference checkout. They would add substantial weight and interrupt the current portfolio's compact reading flow. Claims and numbers in the live portfolio remain grounded in Aditya's resume and the current project descriptions.
